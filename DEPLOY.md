# 🚀 Деплой Örük.AI на Render

Проект готов к деплою одним сервисом: **Dockerfile** сначала собирает React-фронтенд (node:20), затем Python-образ отдаёт API + сайт на одном порту.

## Шаги (5 минут)

1. Открой https://dashboard.render.com → **New +** → **Blueprint**
2. Подключи GitHub-аккаунт (если ещё не подключён) и выбери репозиторий **`Oruk-project`**
3. Render сам найдёт `render.yaml` и покажет сервис `oruk-ai` → **Apply**
4. Жди сборку (~5–8 минут: npm install + pip install)
5. Готово: `https://oruk-ai-xxxx.onrender.com` — сайт + API на одном домене

## Переменные окружения

| Ключ | Что сделать |
|---|---|
| `GEMINI_API_KEY` | необязателен: без него агроном работает в офлайн-режиме 📴 |
| `ORUK_SECRET` | генерируется Render автоматически (ключ JWT) |

## Важно знать (free-план)

- **SQLite живёт внутри контейнера** — при каждом деплое/рестарте данные сбрасываются и база пересеивается демо-данными (это норм для выставки: демо всегда «свежее»)
- Free-сервис **засыпает** после 15 мин без трафика; первый запрос потом занимает ~50 секунд
- Демо-аккаунты работают из коробки (пароль `demo2027`): `farmer_abdireim`, `buyer_osh`, `admin_batken`

## Проверка после деплоя

- `https://<домен>/api/health` → `{"status":"ok","app":"oruk.ai"}`
- `https://<домен>/api/regions` → 23 региона
- `https://<домен>/api/products` → 40 продуктов
- Сайт: главная с графиком обвала 250→25, вход в 1 клик демо-фермером
