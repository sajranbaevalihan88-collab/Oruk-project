# 🍑 Örük.AI — платформа справедливых цен для фермеров Кыргызстана

**StudExpo ОшГУ 2027/2028 • Секция «Экономика юга» • Автор: Сайранбаев Алихан**

---

## Реальная проблема

| Факт | Источник |
|---|---|
| В Баткене абрикос падал с 250 до 25 сом/кг (в 5–8 раз за сезон) | Sputnik KG, Turmush, 2023–2024 |
| 75–90% урожая скупают таджикские/узбекские перекупщики, «сговариваются и сбивают цены» | глава кооператива, Turmush 2025 |
| 90% продукции продаётся без переработки → доходы фермеров не растут | Азаттык, 2018–2025 |
| Сельское хозяйство = 40% ВВП Баткенской области | Азаттык |
| Фермер не знает цену соседнего базара → «все сажают одно и то же → осенью мучаются» | фермер Акылбек, Азаттык |

## Решение

1. **Живая карта цен** — донесения фермеров 1 кнопкой (выбор региона из 23 городов/районов всей страны), справедливая цена = медиана за 14 дней, история по месяцам (график обвала 250→25 сам продаёт проект)
2. **🤖 ИИ-агроном** — «продавать сейчас или подождать?», прогноз на 2–4 недели (тренд с демпфированием + сезонный индекс), советы по сушке/хранению (курага/баргек = ×10 к цене). Gemini API + полноценный офлайн-резерв без ключа
3. **Базар — прямые лоты** — фермер → покупатель, без трёх посредников
4. **Кооперация** — мелкие лоты объединяются в оптовую партию (5 т вместо 0,5 т)

## Каталог и охват

- **40 типичных продуктов Кыргызстана** — от урюка, кураги и грецкого ореха до кымыза, конины, мёда, фасоли и зерновых (RU + KG названия у каждого)
- **23 региона всей страны** — Баткен/Кара-Бак/Кызыл-Кыя, Ош/Узген/Ноокат, Жалал-Абад, Бишкек/Чүй, Талас, Нарын, Ысык-Көл (`/api/regions` — единый список)

## Защита (RBAC, проверено тестами)

- Гость не может сообщить цену → **401**
- Покупатель не может сообщить цену → **403**
- Фермер не может бронировать лот → **403**
- Двойное бронирование лота → **400**
- Перебор партии кооперации → **400**

## Безопасность

JWT (HS256, 7 дней) · пароли pbkdf2_hmac 200k итераций · серверная проверка всех цен/объёмов.
